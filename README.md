# Hi, I'm Shohruh Ismoilov

I build backend services, web applications, and AI integrations.

My focus is simple architecture, reliable APIs, and software that's easy to maintain.

## What I work on

- **Backend:** reactive services with Kotlin, Java, and Quarkus.
- **Web:** applications with SvelteKit, TypeScript, and Tailwind CSS.
- **AI:** Python services with FastAPI, Pydantic, and structured model outputs.
- **Distributed systems:** event-driven workflows with NATS JetStream, gRPC, and Temporal.

## How I build

- Keep designs simple and changes focused.
- Treat tenant isolation and API contracts as core requirements.
- Prefer non-blocking services and explicit concurrency boundaries.
- Validate AI outputs with typed schemas.
- Define success criteria and verify the result.
